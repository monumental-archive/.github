# Scorecard floors, ratcheted (#215): repo, space, minimum score.
# The audit fails a repo whose live score drops below its floor and
# nudges when it rises ~0.3 above (raise the floor, keep the ratchet).
# Regression is the signal, not the absolute number: several checks are
# structurally capped here (Code-Review/Contributors by headcount,
# Fuzzing by subject, Packaging inconclusive by the shared-orchestrator
# design), so an absolute target would be permanently red for reasons
# no work can fix. A repo with a Scorecard shield and no line here is a
# failure: an unfloored badge is a badge nobody is watching.
#
# Two more structural caps, measured 2026-08-13 (#316 addendum D):
# Pinned-Dependencies is dented by the $/.github/actions/canon
# self-reference (#165), which Scorecard parses as an unpinned action;
# Maintained scores 0 for a repo's first 90 days and self-heals.
#
# Signer floored at the LOWER reading, 2026-08-13 (#316): it read 6.9
# when floored and 6.8 on later recomputes with no tree change and
# every earnable check at 10 — Pinned-Dependencies, Dangerous-Workflow,
# Token-Permissions, Vulnerabilities, License and Security-Policy all
# perfect, the residual being Packaging/Signed-Releases inconclusive,
# the headcount checks, and SAST normalised to 9 for PR-only scanning.
# A floor set at an observed HIGH reddens on ordinary recompute drift,
# which is the "expected-red teaches people to ignore gates" failure,
# so the policy in this header — floor low, raise only on the 0.3
# nudge — is applied rather than excepted.
#
# Watermarks, 2026-08-12: the canon read 7 at first probe and 6.9 an
# hour later after the day's thirty-PR churn recomputed — a tenth
# inside the structurally-capped checks, so the floor takes the lower
# reading and the ratchet nudge re-raises it when the score recovers.
# release-lab ratcheted 7.0 → 7.4 on the 2026-08-13 08:44 reading of
# 7.5 (#347): the ratchet nudge fired ("well above floor — raise").
# Floored a tenth under the reading per the drift observation above.
# The same repo read 6.8 that morning on a transient Binary-Artifacts
# 0 ("binaries present in source code") that a fresh run retracted —
# a scanner defect, not a watermark, so it does not set the floor; and
# a single low reading is not evidence of regression (the lesson #347
# records against this file's own header).
# The canon ratcheted 6.9 -> 7.1 on the 2026-08-13 10:19 reading of 7.2
# (#347): the nudge fired ("well above floor — raise"). Floored a tenth
# under the reading, per the drift observation above — the same rule

# a tenth under, per this header's rule. Two things the reading records
